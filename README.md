## Features

### Smart Budget Management
- Visual budget tracking
- Monthly spending overview
- Real-time balance updates

### Easy Expense Logging
- Quick expense entry
- Smart categories
- Optional notes

### Analytics & Insights
- Pie chart breakdown
- Monthly summaries
- Clean dashboard UI

### Personalization
- Light & Dark mode
- Multiple color themes
- Persistent settings

### Data & Privacy
- Local storage only
- Export & import support
- No cloud dependency

---

## How It Works

1. Set your monthly budget  
2. Add daily expenses  
3. View spending insights  
4. Track progress visually
